# Android 账号导出器 · 0.3.0 预览版

手机独立运行的原生 MAUI 入口，协议和数据模型复用此仓库。不需要电脑在线、网页服务或脚本。此项目只提供账号读取和数据导出，不是完整 Helper 的所有自动化功能。

**测试通过、APK 编译成功、真实设备登录成功是不同的验收项。以本次提交的 Actions 结果为准；没有账号的自动化测试不能代替真实游戏引继和系统文件选择器验收。**

## 直接登录、记住账号、保存数据

1. 安装 ARM64 预览 APK，目标 Android 7.0/API24 及以上。
2. 首次在首页输入游戏内的**引继码（用户 ID）和引继密码**，账号备注可不填。引继码支持粘贴分组空格、全角数字，密码按原样提交，不擅自删除首尾空格。
3. 点“引继登录并保存账号”。成功取得登录凭据后，先存入本机安全存储，再进入区服选择和账号读取。**不再要求准备 appsettings.user.json，也不需要电脑协助。**
4. 下次打开 App，已有账号会恢复到选择器中。直接点“读取已保存的账号”，无需再次输入密码，也不会在启动时自动联网登录。
5. 玩家、主线、等级链接、角色与属性、装备与符石、队伍、背包、卡池这 **8 类全部默认勾选**。等级链接仍包含成员，角色与装备仍保留原有详细字段。可以取消部分内容，也有“全选导出内容”按钮；每次启动重新默认全选。
6. 点“生成文件”，默认精简 JSON，也可选按内容拆分的 ZIP。点“保存文件到手机”选择位置，或点“分享已生成的文件”。保存后可从聊天 App 的附件选择器打开，不依赖直接分享兼容性。

同一账号再次引继登录会更新原条目，不重复添加。新增账号保留原有账号，最多 32 个。取消区服选择、读取失败或断网不会自动删除已经保存的账号。登录凭据失效时需要重新引继登录。

“保存”有明确的两个范围：登录账号由 App 自动记住；养成数据文件由用户点“保存文件到手机”保存在所选位置。**不把原始游戏会话或内存快照跨进程持久化**；重启后需要重新读取才能生成新文件，已保存到公共目录的 JSON/ZIP 仍然存在。

## 引继登录的隐私与失败处理

引继流程复用核心 `GetClientKey`，执行 `createUser -> getComebackUserData -> comebackUser`。它不是纯读取操作：会建立临时来源账号并完成游戏端引继，可能影响其他设备的旧凭据。仅对自己有权使用的游戏账号操作，建议先退出游戏，不要并发执行引继。

成功后只保存服务器返回的 ClientKey、账号 ID、备注及必要连接参数，**不保存引继密码**。密码框以密码方式显示、关闭文本预测，提交结束后无论成功失败均清空。原始密码和登录请求不写入普通配置文件、导出文件、控制台或 UI 错误提示。

登录使用独立协议对象，不向运行中的账号管理器提前插入占位账号。校验、交换或保存失败，不覆盖内存中的既有账号；服务器原始异常正文不作为 UI 提示或 InnerException 保留。本机写入失败会专门提示：游戏端引继可能已经生效，不能把“未保存”说成游戏端已经回滚。

核心登录沿用原项目从 `list.moonheart.dev` 读取公共 AuthToken 元数据的步骤；请求该公共文件不附带用户 ID、引继密码或 ClientKey。此预览版没有改写该核心依赖，公共元数据不可用、游戏维护或协议变化仍可能导致真实引继失败。账号引继请求使用经过导入白名单验证的 HTTPS 游戏认证域名。

安全存储仍使用 MAUI SecureStorage。读取失败不自动删除已有数据，用户可显式清除并重新登录。备用的“导入已有登录配置”入口仍支持私有 `appsettings.user.json`，只采用白名单登录字段，不采用导入文件里的自动任务、报告地址和任意本地路径。

**不要把密码、私有登录配置或签名密钥上传到 GitHub、PR、Actions、ChatGPT 或普通群聊。** 通过文件传输配置时，导入成功后请自行删除公共目录中的传输副本。

## 完整导出与快照规则

保持既有 `mementomori-safe-account-export-v3.1` 白名单投影；不为了全选而导出 ClientKey、引继密码、Token、Session、原始 UserId/PlayerId 或游戏 GUID。文件仍含昵称及养成信息，不是完全匿名，请只分享给可信对象。

按既定范围，不在每次生成时自动刷新账号。主动读取时建立快照，重复生成使用该快照。`source.accountDataFetchedAtUtc` 是账号读取时间，`generatedAtUtc` 是文件生成时间。游戏内变更后应再次读取。

卡池现在默认勾选，因此默认生成会额外联网请求卡池列表；其时点可能晚于账号快照。若卡池请求失败，仍保留其他导出内容，在 `gacha.errorType` 中标记失败，不把未取得的卡池信息伪装成有效数据。

生成、保存、分享互相独立；分享或保存已有文件不会再次读取。修改勾选项/JSON 排版/ZIP 格式后需要重新生成。切换账号、重新读取会清除旧文件指示，服务端再次核验导出账号，避免把旧账号快照作为新账号结果。

## 文件权限与清理

文件完整写入私有临时目录后才允许保存或分享。系统保存使用 `ACTION_CREATE_DOCUMENT`，只访问用户选择的文档，不申请全盘存储权限；取消可以重试。复制失败尽力删除新建的不完整文档，某些文档提供器可能不允许删除。

FileProvider 只暴露 `cache/sharing-root/`；路径验证拒绝目录外文件、符号链接和未完成文件。Manifest 关闭系统备份/设备迁移及明文 HTTP。App 禁用可能输出原始协议正文的日志提供者和控制台。

“清除本机账号和临时文件”只清除本 App 保存的凭据和临时导出，不删除游戏账号，也不会删除或撤回已保存、分享的外部副本。清除后不必重启 App 即可重新引继登录。

## 构建与验证

`.github/workflows/android-exporter.yml`：无账号测试 → MAUI Android 与 SDK 依赖 → 自包含 ARM64 开发签名 APK。APK 产物名 `mementomori-exporter-android-arm64-preview`；附有 `SHA256SUMS.txt` 和 `BUILD-INFO.json`（sourceCommit、实际 buildCommit、工作流编号）。测试和完整构建日志分别作为产物保留。

本轮增加无账号测试：引继码校验和 Int64 精度、密码原样传递、不持久化密码、成功后恢复账号、账号去重/多账号、失败不覆盖已有资料、安全存储失败提示、阻止不受支持的地址、默认八项全选、全选 ZIP 的模块与等级链接成员。测试通过受控交换函数，不访问真实账号或执行游戏端引继。

真机仍需验收：全新安装引继登录；密码错误与断网；成功后重启免输密码；取消区服后重新读取；旧账号凭据失效后的重新引继；默认全选及卡池；JSON/ZIP 保存、取消和分享；清除后立即重新登录。Android 真实 SecureStorage、系统文档提供器和真实引继协议不属于无账号单元测试的覆盖范围。

这是**开发签名预览包**，CI 干净环境可能使用不同开发签名，不能保证覆盖旧包安装。卸载重装前应确认自己仍持有有效引继码/密码或可信的私有配置备份，避免无法恢复本机账号。此版本沿用 .NET 9 / MAUI 9 和既有协议依赖，未顺带解决原有 MessagePack 等依赖漏洞警告；正式发布前仍需依赖安全审查、稳定签名和真机验收。
